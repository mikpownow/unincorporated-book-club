THE UNINCORPORATED MEN'S BOOK GROUP WEBSITE

FILES
- index.html: page structure
- styles.css: centered, responsive styling
- script.js: member/year navigation and book data

SETUP
1. Keep index.html, styles.css, and script.js together in one folder.
2. Put bookstack.jpg, the six member icons, and the book-cover images in that same folder.
3. Open index.html in a modern web browser.

Use the year buttons to view selections by year. Click a member card to view all that member's choices. “Show all books” resets the list. The layout is centered and responsive. If an image is missing, the page displays a placeholder for book covers.
